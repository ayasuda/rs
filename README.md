Ramen Simulator
===

ラーメンのレシピを考えて店を経営するスマートフォン向けゲーム「ラーメン屋シミュレーター」の、仕様書とゲーム本体を置くリポジトリ。

ゲーム本体は [game/](game/README.md)（Godot 4.7 / GDScript）。動かし方と実装範囲はそちらを参照。

仕様書は `spec/` にあり、下の目次から GitHub 上でそのまま読める。手元のブラウザで読むなら `make docs` を実行して <http://localhost:3000> を開く（[docsify-cli](https://docsify.js.org/#/quickstart) が必要。`npm i -g docsify-cli` で入る）。
