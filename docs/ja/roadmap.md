# 開発フェーズ構成とタスクリスト：ラーメン屋シミュレーター

本ドキュメントは、「ラーメン屋シミュレーター」の開発における各フェーズのタスクを整理したものである。反復型の開発手法に基づき、企画からリリースまでを4つのイテレーションに分けて進行する。

---

## 🧠 企画・設計フェーズ（Week 1）

| タスク              | 説明                              |
| ---------------- | ------------------------------- |
| ゲーム仕様のFIX        | 各仕様ファイルを統合し、確定バージョンを作成          |
| 画面UI設計（画面一覧・遷移図） | 主要画面の一覧化・画面遷移マップ（PlantUMLなど）を作成 |
| レシピ評価DSLの定義      | レシピ構成→評価ベクトルの型設計と演算処理の仕様化       |
| MVPの範囲決定         | 最小プレイ可能な仕様の抽出と優先実装対象の明確化        |

---

## 🧪 第1イテレーション：レシピクラフト＆顧客評価（Week 2〜3）

| タスク             | 説明                            |
| --------------- | ----------------------------- |
| レシピ構築UIの実装      | 麺・スープ・具材などを組み合わせるインターフェース     |
| 評価ベクトル演算ロジックの実装 | 各構成要素から10軸の数値を集計し、uint16評価を算出 |
| 顧客嗜好ベクトルとの照合    | 顧客の重み・理想値とマッチングして満足度を算出       |
| テキスト・表情での評価表現   | 満足度に応じた感想セリフ・ビジュアルの表示         |

---

## 💰 第2イテレーション：店舗経営・時間管理（Week 4〜5）

| タスク           | 説明                      |
| ------------- | ----------------------- |
| 営業時間設定と固定費モデル | 営業帯ごとのコスト設計と収益バランス計算    |
| 顧客流入ロジック      | 時間帯×カテゴリ×評判による流入数算出     |
| 評判→流入→来客数の実装  | 満足度→評判スコア→流入率の因果連鎖モデル構築 |
| 売上・利益の算出      | 原価自動計算＋価格設定に応じた利益分析     |
| 日送りと経営サイクル表示  | 1日単位の流れを進行し、結果を可視化      |

---

## 🎮 第3イテレーション：ミニゲーム・UX演出（Week 6〜7）

| タスク            | 説明                      |
| -------------- | ----------------------- |
| 接客ミニゲームの実装     | 注文受付→調理→提供のテンポアクション     |
| 満足度に応じた演出      | 表情・感想・来店演出のリアクション表現     |
| サイドメニュー・満腹度の計算 | ラーメンによる満腹占有とサイド注文可能性の判定 |
| 店舗の内装・外観反映     | 外観の清潔感や内装で流入補正（A値）を可視化  |

---

## 🚀 第4イテレーション：マルチプラットフォーム対応とQA（Week 8〜9）

| タスク                       | 説明                             |
| ------------------------- | ------------------------------ |
| Web UI最終調整                | スマホ表示最適化・レスポンシブ設計確認            |
| iOS/Android移植（Capacitor等） | WebViewラップやネイティブ対応設定           |
| セーブ・ロード機能の追加              | プレイ進行データの保存と復元                 |
| 不具合修正・バランス調整              | QAプレイによる問題抽出とパラメータ調整           |
| ストア申請素材準備                 | アイコン・説明文・スクリーンショットなど各ストア提出物の整備 |
