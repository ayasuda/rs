# 3. メニュー・価格戦略 仕様

## 概要

本ゲームでは、仕入れ・在庫管理といったリアルな経営要素は省略し、代わりに「一杯あたりのコスト」「自由な価格設定」「顧客の購買行動（予算・満腹度）」を通じて戦略的な利益コントロールを実現する。

---

## 1. 原価と価格の基本仕様

### ● 原価（ゲーム内での定義）

- 材料の仕入れ管理は行わないが、**ラーメンレシピの内容に応じて自動的に「原価」が計算**される。
- 原価は以下の要素から内部計算される（すべて自動）：
  - 麺種／スープ種／具材数／特殊トッピング数／盛り付け演出 など
  - 原価は情報としてプレイヤーに提示されるが、操作対象ではない。

### ● 価格設定

- プレイヤーはラーメン・サイドメニュー・トッピングに**自由に販売価格を設定**可能。
- 設定価格は、顧客の評価・満足度に影響する。

---

## 2. 顧客の予算と購買行動

### ● 支払い可能予算

顧客は「カテゴリごとの基本予算」に加えて、評判スコアに応じて**支払い上限が上下する**。

```plaintext
支払い上限[c] = 基本予算[c] × (1 + 評判補正[c])
```


例：

学生（基本予算 800円） × 評判補正 +0.25 → 支払い上限 = 1000円

この支払い上限を超える価格設定のラーメンや追加メニューは、購入確率が大きく低下する。

### ● サイドメニューと満腹度

顧客は**「満腹度」ゲージ（0.0〜1.0）**を持っている。

ラーメンの「ボリューム感」が満腹度を占有し、残りの枠でサイドメニューを選ぶ。

```plaintext
満腹消費量 = ラーメンのボリューム感 + サイドメニューのボリューム感
```

* 顧客は 満腹度 ≤ 1.0 を満たす範囲でしか購入行動を取らない。
* したがって、ボリュームの大きいラーメンを提供しているとサイドが売れにくくなる。

## 3. プレイヤーの戦略選択

* ラーメン本体の価格戦略（量と価格のバランス）
* サイドメニューのラインナップ戦略（小腹向け／高単価少量系）
* トッピングのオプション戦略（味の強調／個性付け）

評判が上がれば予算が増えるため、

* 「ボリューム＋低価格で数を取る」
* 「高単価＋高満足度で利益を取る」

など、スタイルに応じた戦略が可能。
