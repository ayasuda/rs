# game — Godot 版ラーメン屋シミュレーター

Godot 4.7（GDScript）で作ったクライアント。サーバーは使わず、評価ロジックも含めてすべてこの中で完結する。

## 動かし方

1. [Godot 4.7 以降](https://godotengine.org/download)（.NET 版でない通常版）を入れる
2. Godot を起動して「インポート」からこのフォルダの `project.godot` を選ぶ
3. F5 で実行

コマンドラインからなら次のとおり（`godot` は Godot の実行ファイル）。

```sh
godot --path game                                    # ゲームを起動
godot --headless --import --path game                # 初回だけ必要（クラス名の登録）
godot --headless --path game -s tests/run_tests.gd   # ロジックのテスト
godot --headless --path game -s tests/ui_smoke.gd    # 画面を一通り操作するテスト
godot --headless --path game -s tests/balance_report.gd  # 各立地で30日回した収支
godot --path game -s tests/screenshots.gd            # 全画面のスクリーンショット（ウィンドウが開く）
```

## 構成

| 場所 | 中身 |
| --- | --- |
| `data/` | マスターデータ（素材・顧客カテゴリ・立地・サイドメニュー）。JSON |
| `scripts/logic/` | 画面に依存しないゲームロジック |
| `scripts/logic/evaluation.gd` | レシピ → 10軸の評価ベクトル、調理技術補正、顧客マッチング、感想 |
| `scripts/logic/economy.gd` | 評判補正・支払い上限・固定費・カバレッジなどの計算式 |
| `scripts/logic/day_simulator.gd` | 1日分の営業シミュレーション |
| `scripts/logic/balance.gd` | バランス調整用の定数 |
| `scripts/autoload/game_state.gd` | 進行データとセーブ／ロード（autoload `GameState`） |
| `scripts/ui/` | 全画面共通の枠（`Screen`）とテーマ |
| `scenes/` | 各画面。`.tscn` は空の Control で、UI は対になる `.gd` がコードで組み立てる |
| `tests/` | テストと確認用スクリプト |

## 仕様書に無くて、こちらで決めたもの

- **数値全般**：顧客カテゴリの嗜好・重み・予算、立地ごとの潜在顧客数と流入率、素材の原価、
  内装・宣伝・研修の費用と効果。すべて暫定値で、`data/*.json` と `balance.gd` にある。
- **満足度の正規化**：`S = Σ w × (D − |r − h|)` の `D` を、仕様の 65535 ではなく 18000 にしている。
  65535 のままだとどんなレシピでも 80〜97 点に収まり、差が出なかったため。
- **調理技術**：仕様の「全軸 +3%・調和性 +5%」を技術 100 のときの値とし、技術が低いほど一杯ごとのブレが大きくなる。
- **夕方の固定費係数**：仕様の表に夕方が無いので、昼と同じ 1.2。
- **席数の扱い**：1営業帯あたり「席数 × 5回転」を上限にしている。
- **価格の効き方**：支払い上限を超えると購入確率が下がり、25% 超で誰も買わない。上限に対する割安・割高は満足度に ±8 点まで影響する。
- **ミニゲーム**：仕様未確定なので、タイミングを合わせるだけの簡易版。精度がその日の調理技術に上乗せされる。

## まだ無いもの

- 特殊軸の補正（調和性を軸のばらつきから算出、創作性を組み合わせの珍しさから算出）。今は素材の寄与値の単純合算
- 構成要素の自作（C1〜C20：自家製麺・自家製スープなど）。今は用意された素材から選ぶだけ
- 常連化、店員の複数人管理、トッピングのオプション販売、チュートリアル、設定画面
- 絵・音。画面は文字とボタンだけ
- 日本語フォントの同梱。今は OS のフォントに頼っているので、実機で崩れるならフォントを入れる
- モバイル向けの書き出し設定。書き出すときは `data/*.json` をエクスポート対象に含める必要がある
  （リソース以外のファイルは既定では含まれない）
