# 立地・物件仕様（来客数ロジックと評判との連動）

## 概要

本仕様では、「立地・物件」要素の中核的な機能として、来客数に影響を与える数式ロジックを定義する。特に、顧客カテゴリ別の基礎流入率と評判スコアが来客数に与える影響に注目し、立地選定がゲーム戦略に直結するよう設計されている。

---

## 1. 立地と来客数の関係

各賃貸物件には、以下のパラメータが設定されている：

- 顧客カテゴリ別の**潜在顧客数**
- 顧客カテゴリ別の**基礎流入率**
- **席数**（＝1日あたりの最大来客数に直結）

来客数は以下の数式により計算される：

```plaintext
来客数[c] = min(潜在顧客数[c] × 実効流入率[c], キャパシティ)
```

## 2. 実効流入率の構成

流入率は、基礎値に複数の補正値を掛け合わせて算出する：

```
実効流入率[c] = B[c] × (1 + R[c]) × (1 + W) × (1 + M) × (1 + D) × (1 + A)
```

| 記号     | 補正要因      | 単位         | 説明                                |
| ------ | --------- | ---------- | --------------------------------- |
| `B[c]` | 基礎流入率     | カテゴリ別      | 店舗立地・通行量に依存する初期設定値                |
| `R[c]` | 評判補正      | カテゴリ別      | 評判スコアに応じた来客補正（初期値50、±50で最大±0.5補正） |
| `W`    | 天候補正      | 共通         | 雨・雪などの天候による補正（例：-0.3）             |
| `M`    | 宣伝効果補正    | 共通またはカテゴリ別 | チラシ・SNS・TVなどによる一時的上昇効果（例：+0.2）    |
| `D`    | 曜日・イベント補正 | 共通         | 曜日・祝日・イベント開催日の影響（例：+0.1）          |
| `A`    | 内装・外観補正   | 共通またはカテゴリ別 | 店舗の清潔感・外観演出による継続的な魅力補正（例：+0.1）    |


## 3. 評判補正 R[c] の算出式

プレイヤーが提供したラーメンが顧客の嗜好とマッチすると、**カテゴリ別評判スコア[R[c]]**が上昇する

評判スコアは基準値50とし、数式としては：

```plaintext
R[c] = (評判スコア[c] - 50) ÷ 100
```

* 評判スコアが上昇することで、流入率が上昇し、来客数が増加
* ただし、店舗の「席数」以上には来客できないため、評判上昇にはキャパ上限がある

## 4. 評価 → 評判 → 来客数 の因果関係

```plaintext
高評価ラーメンの提供
  ↓
カテゴリ別 顧客満足度 上昇
    ↓
評判スコア[c] 上昇
      ↓
流入率[c] 上昇
        ↓
来客数[c] 増加
```


この構造により、プレイヤーが「特定の客層を狙った戦略的なラーメンづくり」や「内装や宣伝による補強」を通じて来客数をコントロールできる設計となっている。

## 5. 営業時間と固定費

### ● 店舗の営業時間設定

- 店舗の営業時間はプレイヤーが選択でき、**営業時間の長さが月次の固定費**に影響する。
- 営業時間帯ごとに固定費係数が設定され、たとえば以下のように加算される：

| 営業帯区分 | 固定費係数 | 備考                     |
|------------|------------|--------------------------|
| 朝営業     | +1.0       | 早朝清掃・準備など含む     |
| 昼営業     | +1.2       | 昼ピークで利益見込み高     |
| 夜営業     | +1.5       | 残業代など含む             |
| 深夜営業   | +2.0       | 光熱・夜間人件費が高い     |

- 固定費 = 基本家賃 × 営業帯合計係数

### ● 流入率への影響（補足）

1日あたりの流入率 `B[c]` は、**営業している時間帯と顧客の生活リズムの重なり**によって有効分が決まる。

```plaintext
実効B[c] = B[c] × 時間帯カバレッジ[c]
```

* 時間帯カバレッジ[c] = 顧客生活リズムと営業時間の重なり率（0.0〜1.0）
* 例：サラリーマン向け店舗が「深夜のみ」営業 → カバレッジ = 0.0 → 流入なし

### ● 経営的意味

* **誰向けに店を開けるか？**が戦略になる
* 客層が広く来る立地では長時間営業が有利だが、固定費リスクも増す
* ニッチ客層向けなら、時間帯を絞って利益最適化も可能

このように、「生活リズム×営業時間×固定費」の三軸が、単なる立地選択にとどまらない戦略性をもたらす。
