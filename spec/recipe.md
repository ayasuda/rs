# レシピクラフト作成の仕様

本ゲームにおける「ラーメンレシピの作成」は、プレイヤーが構成要素を組み合わせて、じぶんの「理想の一杯 」を組み立てるクラフト要素である。
最終的には10個の評価軸により内部数値化され、お客ごとの評価を産み出す。

## レシピの構成要素

* 麺
* スープ
* かえし (タレ)
* 香味油
* 具材 (主役・補助)
* 盛り付け (器・配置)

## 評価軸のリスト

各レシピは、以下に示す 10 の評価軸について、それぞれ uint16 の数値 (0-65535) で内部表現される。

| 評価軸名       |   内容（ラーメンが持つ特徴）                         | 数値化範囲例（uint16）           |
|----------------|------------------------------------------------------|----------------------------------|
| 旨味           | 出汁・かえし・旨味素材による味のベースの厚み         | 0 = 無味 ／ 65535 = 強烈な旨味   |
| 香り           | 香味油・香味素材・調理法による鼻への印象             | 0 = 無臭 ／ 65535 = 強香         |
| 塩味           | かえし・スープの塩気の量                             | 0 = 超薄味 ／ 65535 = しょっぱい |
| 脂の量         | スープ乳化・香味油・脂具材の総量                     | 0 = あっさり ／ 65535 = 背脂系   |
| 甘味           | かえし・具材由来の甘み（みりん・玉ねぎ・煮玉子など） | 0 = 甘さゼロ ／ 65535 = 甘め     |
| 刺激           | 香辛料・唐辛子・ニンニクなどの刺激性                 | 0 = マイルド ／ 65535 = 刺激強   |
| 創作性         | 組み合わせの珍しさ／インパクト／話題性               | 0 = 王道 ／ 65535 = 奇抜         |
| 見た目の美しさ | 彩り／具材配置／器／盛り付けの整合性・印象           | 0 = 雑多 ／ 65535 = 映え         |
| ボリューム感   | 麺量・具材量・厚み・満足感                           | 0 = 少食向け ／ 65535 = 大盛系   |
| 調和性         | 全体のまとまり／各軸の過不足の少なさ                 | 0 = ちぐはぐ ／ 65535 = 一体感   |

創作性と調和性の2軸は、構成要素ごとの点数を持たず、レシピ全体から算出する（ステップ3を参照）。


## 評価値の算出ロジック

本ゲームにおいて、ラーメン一杯の「味の評価」は、以下の手順で10軸の数値評価として内部的に算出されます。この評価は、プレイヤーには直接数値としては表示されず、味の印象や顧客の反応などテキストベースで間接的に伝えられます。

### ステップ1: 構成要素ごとの評価寄与値の定義

各レシピ構成要素（例：スープ、香味油、具材など）は、作成時に、創作性と調和性を除く8つの評価軸に対する「寄与値（contribution）」が個別に算出されます。たとえばプレイヤーが「黒マー油」を香味油として自作した場合、その素材や調理法に応じて「香り」や「脂の量」などへの寄与度が即時に決定されます。

この寄与値は、ゲーム内で定義された各素材・工程のパラメータをもとに内部的に演算され、同じ名前の構成要素であっても、作り方が異なれば寄与値が変わる可能性があります。
たとえば「黒マー油」は「香り」や「脂の量」に強く影響するといった形で設定されます。

### ステップ2: 寄与値の合算

プレイヤーが選択したすべての構成要素について、対応する評価軸への寄与値を加算します。これにより、レシピの評価のうち、創作性と調和性を除く8軸が求まります。各軸の値は0〜65535のuint16範囲でクリップされます。

### ステップ3: 特殊軸の算出

創作性と調和性は、構成要素ごとの寄与値を加算するのではなく、レシピ全体から算出する特殊軸です。

* 「調和性」：全軸の偏差や相関性、過不足の少なさをもとに算出（ばらつきが少ないほど高評価）
* 「創作性」：レア素材の使用、有機的でない組み合わせ、奇抜な盛り付けなどを元にスコアリング（現実性との距離が大きいほど高評価）

この2軸は、構成要素ごとに点数が付いているものではありません。上記は考え方であり、具体的な算出方法は tbd;（別途調整する）。

ステップ2の8軸とこの2軸を合わせた10軸が、レシピとしての評価です。

### ステップ4: 調理技術による補正

レシピとしての評価に対して、調理を担当する店員のスキルや経験値に応じた補正が適用されます。具体的には、店員の「調理技術」パラメータに応じて、

* 評価軸ごとのスコアに微量なブーストを加える
* 調和性のブレを減少させる
* 創作性の暴走を抑える（奇抜すぎて破綻している構成をマイルドに）

といった効果が発動します。これにより、同じレシピであっても、誰が調理するかによって仕上がりの評価が変わるようになります。

調理技術による補正も、具体的な算出方法と数値は tbd;（別途調整する）。

### ステップ5: 顧客との嗜好マッチング

各顧客には10軸の「嗜好ベクトル（H）」が存在し、それぞれの軸について「重みベクトル（W）」も保持しています。この重みは、顧客がどの評価軸を重視するかを示すもので、嗜好ベクトルと完成したラーメンの評価ベクトル（R）との乖離に対してスコアへの影響度を調整します。

満足度スコア（S）は以下のように算出されます：

`S = Σ［w_i × (65535 - |r_i - h_i|)］（i = 1〜10）`

この仕組みにより、同じラーメンであっても「見た目重視の顧客」や「脂好きな顧客」など、各顧客の価値観に応じて評価結果が変動するリアリティのある嗜好評価が実現されます。

## 評価値の算出例

以下に、評価ロジックに基づいて実際にラーメンと顧客の嗜好がどのようにマッチングされるかを示す例を記述します。

### ラーメン例

* 名称：黒香味油の濃厚鶏白湯
* 構成：
  * 高加水太麺
  * 鶏白湯スープ
  * 濃口醤油だれ
  * 黒マー油（香味油）
  * 具材：炙りチャーシュー、味玉、青ネギ
  * 盛り付け：黒どんぶり、放射状配置

### 顧客カテゴリ例

* カテゴリ名：男子大学生
* 嗜好傾向：
  * 脂の量：重視（w = 高）
  * ボリューム感：重視（w = 高）
  * 刺激：やや重視
  * 見た目の美しさ：軽視（w = 低）
  * 調和性：軽視

このような構成において、レシピが脂・ボリューム・刺激性に強く寄与していれば、評価軸とのマッチングにより高い満足度スコアが得られます。反対に、盛り付け重視の顧客ではこのラーメンは低評価となる可能性があります。

### ラーメン評価値の算出 (創作性・調和性)

創作性と調和性は、レシピ全体から算出します。具体的な算出方法は tbd; のため、ここでは仮のロジックを当てはめています。

* 創作性（仮）：定番から外れた組み合わせ・盛り付け1つにつき 4500 を加える
  * 鶏白湯スープに黒マー油を合わせている
  * 盛り付けが放射状配置である
  * → 4500 × 2 = 9000
* 調和性（仮）：寄与値を合算した8軸の、最大値と最小値の差が小さいほど高くする。調和性 = 65535 − (最大値 − 最小値)
  * 最大値は旨味の 35000、最小値は刺激の 3500
  * → 65535 − (35000 − 3500) = 34035

### ラーメン評価値の算出 (調理などの補正後)

以下は、店員の「調理技術」による補正を受けた後の、ラーメンの総合評価値です。調理技術は各評価軸に対して+3%のブースト補正を与えるものとし、調和性に対してはさらに安定化補正（+5%）が加えられた結果です。この補正も仮のロジックです。

| 評価軸               | 合計値（補正前） | 補正係数 | 合計値（補正後） |
|----------------------|------------------|----------|------------------|
| 旨味                 |            35000 |    ×1.03 |            36050 |
| 香り                 |            17000 |    ×1.03 |            17510 |
| 塩味                 |            17000 |    ×1.03 |            17510 |
| 脂の量               |            32000 |    ×1.03 |            32960 |
| 甘味                 |             8000 |    ×1.03 |             8240 |
| 刺激                 |             3500 |    ×1.03 |             3605 |
| 創作性               |             9000 |    ×1.03 |             9270 |
| 見た目の美しさ       |            12500 |    ×1.03 |            12875 |
| ボリューム感         |            12000 |    ×1.03 |            12360 |
| 調和性               |            34035 |    ×1.08 |            36758 |

この補正により、同じレシピでも、調理スキルの高い店員が担当することで味の評価が全体的に底上げされ、顧客満足度が向上する設計となっています。

* 各評価軸における差分 = |ラーメン評価値 − 顧客理想値| を取り、重みを掛けた加重差分を合計。
* 評価スコア = 100 − (加重差分合計 / 正規化定数) ※正規化定数はゲームバランスに応じて決定（例：100000 など）
* 計算例（概略）：
  * 旨味差分：|36050 − 40000| × 1.0 = 3950
  * 脂の量差分：|32960 − 35000| × 1.2 = 2448
  * ボリューム感差分：|12360 − 14000| × 1.0 = 1640
  * ...以下同様に計算し、合計：例えば 12000 程度

→ 評価スコア ≒ 100 − (12000 / 100000) = 88.0

このように、個別の顧客カテゴリごとの嗜好と重みが評価に影響し、プレイヤーの戦略が顧客層に適合していれば高評価を得られる設計となっている。
