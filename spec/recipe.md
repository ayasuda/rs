# レシピクラフト作成の仕様

本ゲームにおける「ラーメンレシピの作成」は、プレイヤーが構成要素を組み合わせて、じぶんの「理想の一杯 」を組み立てるクラフト要素である。
最終的には特徴 8 軸と出来 2 軸の数値として内部表現され、お客ごとの満足度を産み出す。

## レシピの構成要素

* 麺
* スープ
* かえし (タレ)
* 香味油
* 具材 (主役・補助)
* 盛り付け (器・配置)

## レシピの特徴（8軸）と出来（2軸）

各レシピは、次の 10 の軸で内部表現される。10 軸は性質の違う 2 つのグループに分かれる。

* **特徴（8軸）**：好みの分かれる軸。顧客ごとに「理想の値」があり、近いほど良く、遠いほど悪い。多すぎても少なすぎても減点になる。uint16（0〜65535）
* **出来（2軸）**：好みの分かれない軸。誰にとっても、高いほど良い。uint8（0〜255）

### 特徴（8軸）

| 軸名           | 内容（ラーメンが持つ特徴）                           | 数値化範囲例（uint16）           |
|----------------|------------------------------------------------------|----------------------------------|
| 旨味           | 出汁・かえし・旨味素材による味のベースの厚み         | 0 = 無味 ／ 65535 = 強烈な旨味   |
| 香り           | 香味油・香味素材・調理法による鼻への印象             | 0 = 無臭 ／ 65535 = 強香         |
| 塩味           | かえし・スープの塩気の量                             | 0 = 超薄味 ／ 65535 = しょっぱい |
| 脂の量         | スープ乳化・香味油・脂具材の総量                     | 0 = あっさり ／ 65535 = 背脂系   |
| 甘味           | かえし・具材由来の甘み（みりん・玉ねぎ・煮玉子など） | 0 = 甘さゼロ ／ 65535 = 甘め     |
| 刺激           | 香辛料・唐辛子・ニンニクなどの刺激性                 | 0 = マイルド ／ 65535 = 刺激強   |
| 見た目の美しさ | 彩り／具材配置／器／盛り付けの整合性・印象           | 0 = 雑多 ／ 65535 = 映え         |
| ボリューム感   | 麺量・具材量・厚み・満足感                           | 0 = 少食向け ／ 65535 = 大盛系   |

目盛りは 0〜65535 だが、構成要素の寄与値を合算した結果は、どの軸も**概ね 0〜50000 の範囲に収まるように素材を設計する**。顧客の理想値もこの範囲に置く。軸ごとに値の取りうる幅が極端に偏らないこと（ある軸だけ、どう作っても狭い範囲にしかならない、を避ける）も素材設計の指針とする。

### 出来（2軸）

| 軸名   | 内容                                                 | 数値化範囲（uint8）        |
|--------|------------------------------------------------------|----------------------------|
| 創作性 | 組み合わせの珍しさ／インパクト／話題性               | 0 = ありきたり ／ 255 = 独創的 |
| 調和性 | 全体のまとまり／各軸の過不足の少なさ                 | 0 = ちぐはぐ ／ 255 = 一体感   |

この 2 軸は、構成要素ごとの点数を持たず、レシピ全体から算出する（ステップ3を参照）。顧客は 2 軸に理想値を持たない。


## 評価値の算出ロジック

本ゲームにおいて、ラーメン一杯の特徴と出来は、以下の手順で内部的に算出されます。これらの数値はプレイヤーには直接表示されず、味の印象や顧客の反応などテキストベースで間接的に伝えられます。

### ステップ1: 構成要素ごとの評価寄与値の定義

各レシピ構成要素（例：スープ、香味油、具材など）は、作成時に、特徴 8 軸に対する「寄与値（contribution）」が個別に算出されます。たとえばプレイヤーが「黒マー油」を香味油として自作した場合、その素材や調理法に応じて「香り」や「脂の量」などへの寄与度が即時に決定されます。

この寄与値は、ゲーム内で定義された各素材・工程のパラメータをもとに内部的に演算され、同じ名前の構成要素であっても、作り方が異なれば寄与値が変わる可能性があります。
たとえば「黒マー油」は「香り」や「脂の量」に強く影響するといった形で設定されます。

### ステップ2: 寄与値の合算

プレイヤーが選択したすべての構成要素について、対応する評価軸への寄与値を加算します。これにより、レシピの特徴 8 軸が求まります。各軸の値は0〜65535のuint16範囲でクリップされます。

### ステップ3: 出来（2軸）の算出

創作性と調和性は、構成要素ごとの寄与値を加算するのではなく、レシピ全体から算出する特殊軸です。

* 「調和性」：全軸の偏差や相関性、過不足の少なさをもとに算出（ばらつきが少ないほど高評価）
* 「創作性」：レア素材の使用、有機的でない組み合わせ、奇抜な盛り付けなどを元にスコアリング（現実性との距離が大きいほど高評価）

この2軸は、構成要素ごとに点数が付いているものではありません。上記は考え方であり、具体的な算出方法は tbd;（別途調整する）。

ステップ2の 8 軸とこの 2 軸を合わせたものが、レシピの評価ベクトル（R）です。これはレシピそのものが持つ値で、誰が調理しても変わりません。

### ステップ4: 調理による再現

本ゲームにおける「調理」とは、**レシピをどれだけ正確に再現できるか**です。調理によってレシピより良い一杯ができることはなく、レシピが一杯の天井になります。調理を担当する店員の「調理技術」が低いほど、再現が崩れます。

* 特徴 8 軸：それぞれの軸が、レシピの値を中心に**ブレ**ます。ブレの向きは軸ごとに独立で、多くなることも少なくなることもあります。調理技術が高いほどブレ幅は小さく、最高の技術ではレシピの値そのものになります
* 出来 2 軸：単に**減点**されます。調理技術が高いほど減点は小さく、最高の技術では減点されません

このステップの結果が、実際に顧客へ提供される一杯の評価ベクトル（E）です。同じレシピでも、誰が調理するかによって仕上がりが変わります。

ブレ幅と減点の具体的な算出方法と数値は tbd;（別途調整する）。

### ステップ5: 顧客による満足度の算出

顧客は、提供された一杯（E）を **1000 点満点の満足度（S）** で採点します。満足度は、次の 2 つの合計です。

| 部分 | 配点 | 何を見るか |
| --- | --- | --- |
| 特徴の近さ | 0〜800 点 | 特徴 8 軸が、その顧客の理想にどれだけ近いか |
| 出来 | 0〜200 点 | 創作性と調和性の値そのもの（100 点ずつ） |

#### 特徴の近さ（0〜800 点）

各顧客は、特徴 8 軸それぞれについて「理想値（h_i）」と「重み（w_i）」を持ちます。理想値はその顧客にとって一番おいしい値、重みはその軸をどれだけ気にするかです。

軸ごとに、理想値からのずれを正規分布の形で点数にします。理想に近いうちはほぼ満点で、ある程度離れると急に落ち、遠くでは 0 に張りつきます。

```
d_i = e_i − h_i                        # 符号付きのずれ。正なら多すぎ、負なら少なすぎ
s_i = exp( −(d_i / σ)² / 2 )           # 軸ごとの近さ。0〜1。d_i = 0 で 1
近さ = Σ (w_i × s_i) / Σ w_i           # 重み付き平均。0〜1
特徴の近さの点数 = 800 × 近さ
```

σ は「どれだけずれたら不満になるか」を表す許容幅で、全軸・全顧客で共通の 1 つの値です。ずれが σ のとき s_i は 0.61、2σ で 0.14、3σ で 0.01 になります。σ の値はバランス調整で決める（tbd;）。初期値は 6000 とする。

重みは軸どうしの相対的な配分として扱います。合計で割るため、重みを全体的に大きくしても採点が辛くなることはありません。

軸ごとの `d_i` と `s_i` は、満足度の計算に使うだけでなく、顧客の感想（「脂っこすぎた」「ボリュームがちょうどよかった」など）や顧客分析画面の材料にもなります。`d_i` の符号が多すぎ／少なすぎの向き、`s_i` がその軸の満足の度合いです。

#### 出来（0〜200 点）

```
出来の点数 = 創作性 / 255 × 100 + 調和性 / 255 × 100
```

この 2 軸は理想値との比較をせず、値そのものを点数にします。現状は全顧客で同じ効き方ですが、顧客カテゴリごとに重みを持たせる（観光客は創作性を気にする、など）ことを予定しています。持たせ方は tbd;。

#### 満足度

```
S = 800 × 近さ + 創作性 / 255 × 100 + 調和性 / 255 × 100     # 0〜1000
```

この仕組みにより、同じラーメンであっても「見た目重視の顧客」や「脂好きな顧客」など、各顧客の価値観に応じて満足度が変わります。出来の 2 軸は、どの顧客に対しても底上げとして効きます。

## 評価値の算出例

以下に、評価ロジックに基づいて実際にラーメンと顧客の嗜好がどのようにマッチングされるかを示す例を記述します。数値はすべて説明のために置いたもので、実際のバランス値ではありません。

### ラーメン例

* 名称：黒香味油の濃厚鶏白湯
* 構成：
  * 高加水太麺
  * 鶏白湯スープ
  * 濃口醤油だれ
  * 黒マー油（香味油）
  * 具材：炙りチャーシュー、味玉、青ネギ
  * 盛り付け：黒どんぶり、放射状配置

### 顧客カテゴリ例

* カテゴリ名：大学生
* 嗜好傾向：
  * 脂の量：重視（w = 高）
  * ボリューム感：重視（w = 高）
  * 刺激：やや重視
  * 見た目の美しさ：軽視（w = 低）

このような構成において、レシピが脂・ボリューム・刺激性に強く寄与していれば、評価軸とのマッチングにより高い満足度スコアが得られます。反対に、盛り付け重視の顧客ではこのラーメンは低評価となる可能性があります。

### ラーメン評価値の算出 (出来 2 軸)

創作性と調和性は、レシピ全体から算出します。具体的な算出方法は tbd; のため、ここでは仮のロジックを当てはめています。

* 創作性（仮）：定番から外れた組み合わせ・盛り付け1つにつき 45 を加える
  * 鶏白湯スープに黒マー油を合わせている
  * 盛り付けが放射状配置である
  * → 45 × 2 = 90
* 調和性（仮）：8 軸の合計値を実用範囲の上限 50000 で割って 0〜1 にし、その最大値と最小値の差が小さいほど高くする。調和性 = 255 × (1 − (最大 − 最小))
  * 最大は旨味の 0.70、最小は刺激の 0.07
  * → 255 × (1 − 0.63) ≈ **94**

### 調理による再現

この例では、最高の調理技術を持つ店員が調理したものとし、レシピの値がそのまま提供される一杯の値（E）になります。技術が低い店員なら、8 軸はこの値を中心にブレ、創作性・調和性はここから減点されます。

### 顧客満足度の算出

大学生の理想値と重み（例として置いた値）、および σ = 6000 で計算します。

| 軸             | 一杯の値 e_i | 理想値 h_i | ずれ d_i | 近さ s_i | 重み w_i | w_i × s_i |
|----------------|-------------:|-----------:|---------:|---------:|---------:|----------:|
| 旨味           |        35000 |      36000 |    −1000 |    0.986 |      1.0 |     0.986 |
| 香り           |        17000 |      17000 |        0 |    1.000 |      0.7 |     0.700 |
| 塩味           |        17000 |      17000 |        0 |    1.000 |      0.6 |     0.600 |
| 脂の量         |        32000 |      33000 |    −1000 |    0.986 |      1.2 |     1.183 |
| 甘味           |         8000 |       8000 |        0 |    1.000 |      0.4 |     0.400 |
| 刺激           |         3500 |       6000 |    −2500 |    0.917 |      0.8 |     0.733 |
| 見た目の美しさ |        12500 |      12000 |     +500 |    0.997 |      0.4 |     0.399 |
| ボリューム感   |        12000 |      16000 |    −4000 |    0.801 |      1.2 |     0.961 |
| **合計**       |              |            |          |          |  **6.3** | **5.963** |

* 近さ = 5.963 ÷ 6.3 = 0.947
* 特徴の近さの点数 = 800 × 0.947 ≈ **757 点**
* 出来の点数 = 90 ÷ 255 × 100 + 94 ÷ 255 × 100 = 35.3 + 36.9 ≈ **72 点**
* 満足度 S = 757 + 72 = **829 点**（1000 点満点）

一番ずれているのはボリューム感（4000 少ない）で、重みも大きいので、この顧客の感想は「量が少し物足りない」が最初に出ます。ずれが小さく重みの大きい旨味・脂の量は「しっかりしていた」「ちょうどよかった」の褒め言葉になります。
